## 🔴 MONOPOLIO (SUPER IMPORTANTE)

**Maximización:**
```
IMg = CMg
```

**Si P = a - bQ:**
```
IMg = a - 2bQ  (doble pendiente)
```

**Índice de Lerner:**
```
L = (P - CMg)/P = 1/|elasticidad|
```

**PIE (Pérdida Irrecuperable Eficiencia):**
- Monopolio produce MENOS que competencia perfecta
- P > CMg → consumidores no pueden comprar aunque valoración > costo
- Triángulo de pérdida social

**EJEMPLO RÁPIDO:**
```
P = 100 - Q, CMg = 50
IMg = 100 - 2Q
100 - 2Q = 50 → Q* = 25, P* = 75
Lerner = (75-50)/75 = 33%
```

## 🔴 DISCRIMINACIÓN PRECIOS (SUPER IMPORTANTE)

**Tipo 3 (Por segmentos):**

**Regla de oro:**
```
(Pi - CMg)/Pi = 1/|elasticidad_i|
```

**Implicación clave:**
- Mercado MENOS elástico → Paga MÁS
- Mercado MÁS elástico → Paga MENOS

**Método solución:**

**SIN discriminar:**
1. Igualar P1 = P2
2. Encontrar Q2(Q1)
3. Maximizar beneficio en Q1
4. Calcular beneficio total

**CON discriminar:**
1. Maximizar cada mercado por separado: IMg_i = CMg
2. Sumar beneficios
3. Comparar con caso sin discriminar

**Beneficio CON discriminación SIEMPRE > SIN discriminación**

**4 Fricciones necesarias:**
1. Imposibilidad física reventa (servicios)
2. Costos transacción altos
3. Información imperfecta
4. Restricciones legales

**Producto dañado:** Versión degradada intencionalmente para autoselección

## 🔴 TEORÍA DE JUEGOS (IMPORTANTE)

**Estrategia Dominante:**
- Óptima INDEPENDIENTE de lo que haga el rival

**Equilibrio de Nash:**
- Ningún jugador mejora cambiando UNILATERALMENTE
- Mejor respuesta mutua

**Cómo encontrar Nash:**
1. Para CADA jugador, subraya su mejor respuesta a cada estrategia del rival
2. Celdas con AMBOS pagos subrayados = Nash

**Dilema del Prisionero:**
- Estrategia dominante para ambos: Confesar
- Nash: (Confesar, Confesar)
- Problema: Es ineficiente (hay resultado mejor para ambos)
- Aplicación: Guerras de precios, carreras armamentistas

**Juegos Repetidos:**
- Cooperación SOSTENIBLE si:
  * δ (paciencia) suficientemente alto
  * Pueden detectar desviaciones
  * Pocos jugadores
  
**Condición:**
```
δ ≥ (ganancia_desvío - ganancia_coop)/(ganancia_desvío - ganancia_Nash)
```

## 📊 CONCENTRACIÓN

**HHI (Herfindahl-Hirschman):**
```
HHI = Σ(cuota_mercado_i)²
```

**Clasificación:**
- HHI < 1,500: No concentrado
- 1,500-2,500: Moderado
- HHI > 2,500: Altamente concentrado

**Relación con poder de mercado:**
```
Lerner_industria = HHI/|elasticidad|
```

---

## 📐 ELASTICIDAD

**Definición:**
```
elasticidad = -(dQ/dP) × (P/Q)
```

**Clasificación:**
- |η| > 1: Elástica (sensible a precio)
- |η| = 1: Unitaria
- |η| < 1: Inelástica (poco sensible)

**Relación con Lerner:**
```
L = 1/|elasticidad|
```

**Interpretación:**
- Demanda inelástica → Más poder de mercado → Margen mayor

## 🎯 OLIGOPOLIO

**Cournot (cantidades):**
- Empresas eligen Q simultáneamente
- P > CMg pero < monopolio
- Más empresas → Más competitivo

**Bertrand (precios):**
- Empresas eligen P simultáneamente
- Con productos homogéneos: P = CMg
- Paradoja: 2 empresas = competencia perfecta

**Stackelberg (secuencial):**
- Líder mueve primero
- Ventaja primer movimiento
- Líder produce más que en Cournot

## 🚨 ERRORES COMUNES A EVITAR

❌ **Olvidar que IMg tiene doble pendiente** que demanda
✅ IMg = a - 2bQ (no a - bQ)

❌ **Pensar que discriminación es ineficiente**
✅ Discriminación perfecta ES eficiente (pero redistribuye)

❌ **Confundir estrategia dominante con Nash**
✅ Dominante: óptima SIEMPRE | Nash: óptima DADO rival

❌ **Creer que HHI alto = siempre malo**
✅ Puede reflejar eficiencia (Escuela Chicago)

❌ **Olvidar CMg en Lerner**
✅ L = (P-CMg)/P (no solo P)
