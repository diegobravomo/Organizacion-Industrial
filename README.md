# 📚 Central de Estudio: Organización Industrial (USACH)

> Hub de investigación para optimizar el aprendizaje mediante flujos de trabajo eficientes.

## 🎯 Objetivo

Dominio de modelos de mercado y preparación rigurosa de exámenes en Organización Industrial.

## 📂 Estructura del Repositorio

```
Organizacion-Industrial/
├── README.md                    # Este archivo
├── resumenes/                   # Resúmenes ejecutivos e insights teóricos
│   └── README.md               # Índice de resúmenes
├── visualizaciones/            # Diagramas Mermaid y dashboards de modelos
│   └── README.md               # Catálogo de visualizaciones
└── audio-scripts/              # Guiones técnicos para repaso auditivo
    └── README.md               # Guía de audio-scripts
```

## 🔧 Funcionalidades

### 1. 📝 Resúmenes Ejecutivos e Insights Teóricos
Síntesis de bibliografía y apuntes con enfoque en conceptos clave y aplicaciones prácticas.

### 2. 📊 Visualizaciones
- **Diagramas Mermaid**: Representaciones visuales de estructuras de mercado
- **Dashboards de Modelos**: Visualización de equilibrios y comportamientos estratégicos

### 3. 🎧 Audio-Scripts
Guiones técnicos optimizados para repaso auditivo de fórmulas y conceptos fundamentales.

## 📖 Contenido Principal

### Modelos de Mercado Cubiertos
- Competencia Perfecta
- Monopolio
- Oligopolio (Cournot, Bertrand, Stackelberg)
- Competencia Monopolística
- Teoría de Juegos aplicada

## 🚀 Cómo Usar este Repositorio

1. **Navegar por secciones**: Cada carpeta contiene un README.md con índice
2. **Visualizar diagramas**: Los diagramas Mermaid se renderizan automáticamente en GitHub
3. **Audio-scripts**: Usar los guiones para crear grabaciones de repaso
